# Single Screen Rebuild Plan
We are replacing the old patched app with one clean single-screen quote app.
Main requirements:
- One page only
- One customer checkout / preview / print workflow
- Style selector (Lakeland, Malibu, etc.)
- Product image preview on page
- Wholesale / Retail / Auto pricing
- Material only / Labor only / Materials + Labor
- Show prices / Hide prices / Mask prices
- Draggable gate
- Swing direction selector
- Clean map
- Quote totals and customer print control
