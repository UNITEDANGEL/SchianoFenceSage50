Fence Visual Catalog

Files:
- config\fence_visual_catalog.json
- catalog_images\*.svg
- app\visual_catalog_v10.js

How it works:
- The app reads fence_visual_catalog.json.
- It matches manufacturer + material + style + color + height.
- It shows the fence image in the app.
- Print Quote With Image prints the selected image on the quote.
